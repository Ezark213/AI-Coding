### スライドマスターについて

**重要**: 左上のティール色要素（四角・縦バー）は、本来は**スライドマスター（デザインテンプレート）**で設定されます。

- PowerPointの「表示」→「スライドマスター」で設定
- マスターに配置することで、全スライドに自動適用される
- 手動で各スライドに追加する必要がなくなる

Pythonで生成する場合は、マスターを含むテンプレートファイル（.potx）を使用するか、各スライドに手動で図形を追加します。

## Python生成コード例

```python
from pptx import Presentation
from pptx.util import Cm, Pt
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN, MSO_ANCHOR
from pptx.enum.shapes import MSO_SHAPE

# カラー定義
TEAL = RGBColor(0, 150, 167)
BLUE = RGBColor(0, 112, 192)
DARK_TEXT = RGBColor(51, 51, 51)
GRAY = RGBColor(128, 128, 128)
WHITE = RGBColor(255, 255, 255)

# サイズ定義
SLIDE_NUM_WIDTH = Cm(2.05)
SLIDE_NUM_HEIGHT = Cm(1.52)
COVER_TEAL_SIZE = Cm(2.12)
TITLE_BAR_WIDTH = Cm(0.4)
TITLE_BAR_HEIGHT = Cm(0.8)

# 使用例は上記スクリプト参照
```

## Tips

### 効果的なスライド作成のポイント

1. **1スライド1メッセージ** - タイトルで結論がわかるように
2. **数字で語る** - 「大幅に削減」→「40%削減」
3. **図表優先** - 文章より視覚的に
4. **ARMAスタイル統一** - ティール/青のカラーを守る

### スライドマスターの活用

本来、左上のティール要素はスライドマスターで設定します：
1. PowerPoint「表示」→「スライドマスター」
2. マスターに四角/縦バーを配置
3. 全スライドに自動適用される
